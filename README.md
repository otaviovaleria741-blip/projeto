# Meus estudos de Python

Programas que escrevi aprendendo Python, do primeiro dia em diante.

## O que tem aqui

| Arquivo | O que faz | O que aprendi |
|---|---|---|
| `primeiro.py` | pergunta nome e idade, calcula quantos dias você viveu | entrada de dados, conversão de tipo |
| `calculadora.py` | calculadora com as quatro operações | decisão em cadeia, tratamento de erro, repetição |
| `jogo.py` | jogo de adivinhar um número de 1 a 100 | biblioteca `random`, contador |
| `pedra-papel-tesoura.py` | pedra, papel e tesoura no terminal, melhor de 3 | condições compostas, laço com condição de parada |
| `jogo_web.py` | o mesmo jogo, como aplicação web | Streamlit, estado, listas e dicionários |

## Como rodar

Os quatro primeiros rodam direto:

```bash
python3 calculadora.py
```

O último é uma aplicação web:

```bash
pip install streamlit
streamlit run jogo_web.py
```
